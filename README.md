# Lunars UABEA

A Unity asset bundle editor for Windows, based on UABEA (MIT).

## Download

1. Go to **[Releases](https://github.com/roleplayleecounty-collab/LunarsUABEA/releases/latest)**
2. Download `LunarsUABEA-win-x64.zip`
3. Extract it and run `LunarsUABEA.exe` (no .NET install needed)
